# 长夜 · 原型 v0.4

按 `docs/spec-novel-review-app.md` 做的可点原型，纯 HTML/CSS/JS，无依赖、无构建、不联网。
双击 `index.html` 打开。

## 这一版改了什么

**从"演示品"变成"空壳"。** 打开是空的，所有内容都要自己加。

| 旧 | 新 |
| --- | --- |
| 主页两个按钮 | 主页只剩背景，左侧隐藏抽屉 |
| 写死的《长夜将尽》 | 空书架，自己新建系列 |
| 写死的正文/设定 | 导入正文、写设定 |
| 写死的评论 | 生成出来的，可删 |
| 单一背景 | 默认图集 + 自定义图集 |

## 怎么用

1. 主页左上角 ☰（或向右滑）打开书架
2. ＋ 新建系列 → 进入系列 → 导入正文
3. 正文页底部「短评 / 长评」自动生成第一批
4. 长按可以删：系列、正文、设定、评论、同人
5. 设置 → 背景：切「默认 / 自定义」，自定义可上传、可删

## 四个删除入口

- 书架里长按系列 → 重命名 / 删除
- 正文列表长按作品 → 删除
- 设定集长按条目 → 删除
- 短评/长评/同人长按 → 删除

## 背景

- **默认**：8 张，系统自带，不可删
- **自定义**：从相册选，自动裁成竖屏并压缩，可删
- 设置里选哪套参与轮换；每次进入封面随机换一张

## 哪些还是假的

| 项 | 现状 |
| --- | --- |
| 评论内容 | 本地模板 + 从你导入的正文里摘句子，**不是模型输出** |
| 余额 / 用量 | 未接真实接口，显示「—」 |
| 数据存储 | 浏览器 localStorage；卸载/清数据即丢 |
| 图片 | 默认 8 张是程序画的，不是实拍 |

**关于"评论"**：没填 API Key 时，生成走本地模板（会引用你正文里的原句，所以看起来像有人在读）。填了 Key 也不会真的调用——这一版还没接模型，只留了配置位。等接上之后，替换 `makeShort / makeLong / makeDoujin` 三个函数即可。
