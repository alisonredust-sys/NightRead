## 1. 一句话定义

每天用数字键盘记一个体重、一个体脂率、六顿吃的东西，按任意起止日期导出 Excel，并在应用内查看该区间的平均体重与体重曲线。

> 需求原文中的「简易计算器」指**统计面板**（算平均值、画曲线），不是四则运算器。本文档按此理解。

## 2. 范围

### 2.1 做什么

1. 每日记录：体重、体脂率（数字键盘，或标记「未记录」）。
2. 每日六餐文本：早餐 / 上午 / 午餐 / 下午 / 晚餐 / 夜宵，任意一顿可留空。
3. 历史浏览与补记：可翻到任意过去日期查看、修改、删除；未来日期不可录入。
4. Excel 导出：自选起止日期，导出为 `.xlsx`，写入「下载」目录。
5. 区间统计：平均体重（含样本量）、最高/最低、首尾差与变化率、体重折线图。

### 2.2 明确不做

| 不做 | 理由 |
| --- | --- |
| 账号、云同步、多设备 | 单人自用（D3） |
| 备份 / 恢复 | 用户两次选择最简方案（D24） |
| 每日提醒通知 | D23 |
| 目标体重、进度条 | D19 |
| 体脂率曲线 | D18 |
| 食物热量库、克数、营养素 | 需求只要求"能打字"（D7） |
| 多用户、iOS、商店上架、多语言 | 范围外 |

## 3. 数据模型

单表 `daily_record`，一天至多一行：

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `date` | TEXT | PK，唯一 | `yyyy-MM-dd`，自然日（D6） |
| `weight_kg` | REAL | 可空 | 以 kg 存储，2 位小数 |
| `body_fat_pct` | REAL | 可空 | 百分比数值，1 位小数 |
| `breakfast` | TEXT | 可空 | 早餐 |
| `morning` | TEXT | 可空 | 上午 |
| `lunch` | TEXT | 可空 | 午餐 |
| `afternoon` | TEXT | 可空 | 下午 |
| `dinner` | TEXT | 可空 | 晚餐 |
| `supper` | TEXT | 可空 | 夜宵 |
| `created_at` | INTEGER | NOT NULL | epoch millis |
| `updated_at` | INTEGER | NOT NULL | epoch millis |

**空值语义（D5）**：`NULL` = 未记录。不存 0、不存「未记录」字样、不设哨兵值。体重与体脂互相独立——可以只记体重不记体脂。

**单位换算（D11）**

- 界面与导出主单位：斤，1 位小数。
- 存储单位：kg，2 位小数。`kg = 斤 / 2`，`斤 = kg × 2`。
- 输入 128.5 斤 → 存 64.25 kg → 回显 128.5 斤（可无损往返）。
- 键盘只允许输入 1 位小数，因此"存 2 位"永远够用。

**写入规则（D4）**：按 `date` upsert，同一天只可能有一条记录。

## 4. 界面与交互

### 4.1 记录页（默认 tab）

```

│                       [回到今天] │   点日期区：弹日历跳转
├─────────────────────────────────┤
│  体重          128.5 斤  [未记录] │   点数值区 → 弹出数字键盘
│  体脂率         23.4 %   [未记录] │
├─────────────────────────────────┤
│  早餐  ┌───────────────────────┐ │
│        │ 两个鸡蛋、一杯豆浆      │ │   多行文本，自动保存
│        └───────────────────────┘ │
│  上午  ┌───────────────────────┐ │
│        │                       │ │
│        └───────────────────────┘ │
│  午餐  ┌───────────────────────┐ │
│  下午  ┌───────────────────────┐ │
│  晚餐  ┌───────────────────────┐ │
│  夜宵  ┌───────────────────────┐ │
└─────────────────────────────────┘
```

规则：

- 页面打开时定位到今天；顶部始终显示当前编辑的日期，避免"改错天"。
- 未来日期：右箭头在「今天」时置灰；日历中今天之后的日期不可选（D12）。
- 过去日期：可任意选择补记（下限 2000-01-01）。
- [`回到今天`] 常驻，翻远了能一键回来（D21）。
- 删除：页面右上角菜单 →「删除当天记录」→ 二次确认（D22）。删除后返回今天。

### 4.2 数字键盘（自绘）

点体重/体脂的数值区，从底部升起**自绘键盘**（不遮挡表单，不调用系统输入法）：

```
┌───────────────┬──────┐
│  1    2    3  │  ⌫   │
│  4    5    6  │ 未记录│
│  7    8    9  │ 完成 │
│  .    0       │      │
└───────────────┴──────┘
```

- 只允许 1 位小数；`.` 只在尚未出现小数点时可点。
- 「未记录」= 清空该字段并写 NULL。
- 「完成」= 收起键盘、写库。
- 输入非法（超范围）时不接受该次按键，键位短暂变红提示。

## 5. 统计口径（精确定义）

### 5.1 符号

区间 `[D1, D2]`，总天数 `N = D2 − D1 + 1`。
`S` = 区间内 `weight_kg` 非空的日期集合，`n = |S|`。

### 5.2 计算

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 平均体重 | `mean(weight_kg for S) × 2`，1 位小数 | 分母是 **n**，不是 N |
| 有效天数 | `n / N` | 必须与平均值同时显示 |
| 最高 / 最低 | `max / min(weight for S) × 2` | 无数据时显示 `—` |
| 首尾差 | `weight(最早有记录的日期) − weight(最晚有记录的日期)` | 不是"最高−最低" |
| 变化率 | `首尾差 / 最早值 × 100%` | 带正负号，1 位小数 |

所有计算在 kg 上完成后统一换算为斤显示，避免"先四舍五入再相减"产生的误差。

### 5.3 边界

| 情况 | 表现 |
| --- | --- |
| n = 0 | 平均值、极值、变化率全部显示 `—`，文案「区间内没有体重记录」 |
| n = 1 | 平均值/最高/最低 = 该值；首尾差与变化率显示 `—`；图上只画一个点 |
| n ≥ 2 | 正常 |

### 5.4 图表

- **横轴**：日历等距——区间内每一天占同样宽度，缺记的天只是没有点（D20）。
- **纵轴**：体重（斤），范围 `[min − 1, max + 1]` 取整。
- **线型**：相邻两个有效点之间——
  - 日期相邻（间隔 1 天）→ **实线**
  - 跨缺失日（间隔 > 1 天）→ **虚线**（标记这是插值，不是测量）
- **刻度标签**：区间 ≤ 90 天显示每 7 天一个日期；> 90 天只显示首、中、尾与每月 1 日。
- 体脂率不上图（D18）。

## 6. 导出规格

### 6.1 文件

- 格式：`.xlsx`（Office Open XML），单 sheet，表名 `记录`（D14）。
- 文件名：`diet_<起:yyyyMMdd>_<止:yyyyMMdd>.xlsx`。
- 位置：系统「下载」目录（MediaStore，无需存储权限），重名自动追加 `(1)`。
- 导出后提示完整路径，并提供「分享」。

### 6.2 列

| 列 | 内容 | 类型 / 格式 |
| --- | --- | --- |
| A | 日期 | 真日期，显示 `yyyy-mm-dd` |
| B | 体重(斤) | 数值，1 位小数 |
| C | 体重(kg) | 数值，2 位小数 |
| D | 体脂率(%) | 数值，1 位小数 |
| E–J | 早餐、上午、午餐、下午、晚餐、夜宵 | 文本，自动换行，垂直顶端对齐 |

- 第 1 行表头加粗、浅灰底、冻结首行。
- **行数 = N**：区间内每一天都有一行；无记录的天只填 A 列日期，B–J 留空（D13）。
- 日期按升序排列。
- 列宽：A 12、B/C/D 10、E–J 30。

### 6.3 不做

- 不导出于多 sheet、不做图表嵌入、不做合计行（合计在 App 内看）。
- 不打乱原表顺序；空白天就是空白天，不裁剪（否则无法看出漏记）。

## 7. 技术方案（D27）

| 层 | 选型 |
| --- | --- |
| 语言 / UI | Kotlin + Jetpack Compose（单 Activity） |
| 数据库 | Room（SQLite），单表 |
| 导航 | 两个 tab（记录 / 统计）+ 导出页；用状态或 Navigation-Compose |
| 图表 | Compose `Canvas` 自绘折线（不引第三方图表库） |
| 键盘 | 自绘 `Keyboard`-like 组件，不使用系统输入法 |
| xlsx | `java.util.zip` 手写 OOXML（workbook.xml / sheet1.xml / styles.xml / sharedStrings 可选） |
| 文件落盘 | MediaStore.Downloads（API 29+），API 26–28 走 `WRITE_EXTERNAL_STORAGE` 分支 |
| 权限 | 无 INTERNET、无定位、无通知；仅旧版本需要写存储权限 |

体积目标：APK < 15 MB。

## 8. 构建与交付（D25 / D26）

1. 在本机安装 JDK 17（现有 JDK 25 对 AGP 偏新）与 Android SDK cmdline-tools，SDK 装到 L 盘。
2. 用 Gradle wrapper 固定构建工具版本；依赖优先走国内镜像（`services.gradle.org` 首包 18s，偏慢）。
3. 产出 `app-debug.apk`（debug 签名），用户自行传输安装。
4. 同时交付源码与一份「如何重新构建」的说明。

## 9. 验收清单

- [ ] 全新安装，打开即为今天，七个字段可录入并回显
- [ ] 杀进程重开，数据仍在
- [ ] 体脂留空、体重有值；体重留空、体脂有值——两种都正常保存与显示
- [ ] 点「未记录」后该字段变空，统计中该天不计入 n
- [ ] 左箭头可翻到昨天补记，今天数据不受影响；右箭头在今天置灰
- [ ] 日历中未来日期不可选
- [ ] 同日多次修改只保留一条记录
- [ ] 统计：n=0 / n=1 / n≥2 三种文案正确
- [ ] 统计：平均值分母为有效天数，且「n / N」可见
- [ ] 图表：横轴按日历等距；跨缺失段为虚线；单点不成线
- [ ] 导出：行数 = 区间天数；空白天保留；日期在 Excel 中可排序
- [ ] 导出文件出现在「下载」，文件名含起止日期，可分享
- [ ] 删除需二次确认，删除后该日不影响统计
- [ ] 应用无网络请求、无常驻通知
