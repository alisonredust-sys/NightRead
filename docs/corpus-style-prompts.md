## 一、短评

### 数据长什么样

| 指标 | 数值 |
| --- | --- |
| 一批的条数 | 10–16 条，多数 12–14 |
| 单条长度 | 中位 **23 字**，均值 34，90% 分位 88 |
| 感叹号 | **9.3 / 千字**（三类里最高） |
| 问号 | 4.1 / 千字 |
| 破折号 | 4.5 / 千字 |
| 第一人称「我」 | 9.5 / 千字 |
| 第二人称「你」 | 7.2 / 千字 |

### 读出来的样子

**格式是固定的**：`**用户「昵称」** ★★★★★` + 正文。昵称几乎全是**玩梗的读者 ID**——`清霜我老婆`、`只看甜文的咸鱼`、`考据党不吃香菜`、`清霜x白露民政局`、`夜雁是我家小狗`、`设定警察`、`纯路人`。

**第一句就开火**，没有铺垫：

> 跨年夜看到这篇真的破防了。
> 有意思。
> 夜雁！！！妈妈爱你！！！（破音）

**引用是为了接着反应**，不是复述剧情：

> 朝舞最后那句"我很幸运，无论驻足或是前进，我都和她们在一起"直接让我眼泪掉下来。

**同一个细节会被好几个人反复提起**（"黑芝麻紫薯汤圆"在不同评论里出现了三次），这是评论区真实感的来源——读者会注意到同一处。

**一批里有分工**：角色厨、CP 党、考据党、路人、差评、催更各占几条。3–4 星的差评是必要的（"没什么情节啊……看到一半差点睡着"）。

**括号是补刀位**：（破音）（认真）（不是）（褒义）（被夜雁拖走）。

**结尾落在"求"上**：求作者写 XX 外传、求续集、好想摸、想养一只。

### 正面提示词（主体）

```text
写一批小说网站的读者短评，12–14 条。

每条的格式是两行：第一行「用户「昵称」」加星标，第二行正文。
昵称要像真实读者的 ID：角色名 + 身份/关系/口号（例：清霜我老婆、考据党不吃香菜、
只看甜文的咸鱼、设定警察、纯路人）。同一批里不许重样。

正文写法：
· 第一句直接给反应或判断，不铺垫。「跨年夜看到这篇真的破防了」这种起手。
· 引一句原文的动作或台词，加引号，紧接着说这个细节为什么戳人。
· 说话对象是角色本人或作者，用「你」「求你」「想」，不用「本文」「该书」。
· 允许括号补刀：（破音）（认真）（不是）（褒义）。
· 每条 60–200 字，3–6 句，句号少、感叹号多。
· 结尾常落在「想」「求」「期待」上。

一批里要有分工：
· 3–4 条角色厨，直接对角色说话，情绪外放；
· 2–3 条 CP 党，把两个角色的互动读成关系；
· 2 条考据党，盯设定、时间线、伏笔；
· 2 条普通读者，说自己的阅读体验；
· 1 条差评，3 星，指出具体哪里松、哪里淡；
· 1 条催更。

星标以五星为主，差评给三星，考据党可以四星。
```

### 少量负面

```text
不要写「综上所述」「本文」「该书」「作者通过」。
不要每条都夸——一批里至少要有一条是真的不满意。
不要在结尾总结全文。
```

## 二、长评

### 数据长什么样

| 指标 | 数值 |
| --- | --- |
| 篇幅 | 中位 **3169 字**，均值 3433 |
| 感叹号 | **0.8 / 千字**（几乎是短评的 1/12） |
| 问号 | 1.0 / 千字 |
| 第一人称「我」 | 2.4 / 千字（低） |
| 「作者」 | 2.6 / 千字 |

**短评和长评的分界线不在长度，在情绪浓度。** 长评几乎不用感叹号，第一人称也压得很低，是"评论文章"的语域。

### 读出来的样子

**开篇一句总判断**，然后报菜单：

> 这篇《重置点》是一篇充满生活气息与人文温度的短篇作品……以下将从六个角度对这篇小说进行详细赏析：

**固定六节**，每节一个"四字判断"做小标题：

> ### 1. 故事情节：于无声处听惊雷
> ### 2. 人物形象：四种灵魂，一种羁绊
> ### 3. 行文节奏：张弛有度的呼吸感
> ### 4. 语言风格：轻盈灵动与哲学思辨的交织
> ### 5. 描写细节：于细微处见真情
> ### 6. 主题主旨：重置点的哲学——意义在于共在

**每节内部是"论点 + 术语加粗 + 原文作证"**：

> * **切片式叙事：** 作者巧妙地选择了一个极具象征意义的时间节点……
> * **起承转合的内化：** 情节的推进并非依赖外部事件，而是依赖对话的深入。

**评价词高度集中**：巧妙地、精准地、极为出色、拿捏得恰到好处、成功塑造、极具辨识度。

**引文是嵌在句子里的**，不加书名号也不单独成行：

> 开篇描写"上下颠倒的流星雨"、"闪着刺眼光芒的星辰们从楼下飞射而上"，用反逻辑的比喻……

### 正面提示词（主体）

```text
写一篇 2500–3500 字的小说赏析。

开头一句总判断，句式是「这篇《X》是一篇……的作品，通过……勾勒出……」，
然后接一句「以下将从六个角度对这篇小说进行详细赏析」。

正文六节，每节标题格式是「### 序号. 四字主题：一句判断」，例如
「### 1. 故事情节：于无声处听惊雷」「### 2. 人物形象：四种灵魂，一种羁绊」。
六节固定为：故事情节、人物形象、行文节奏、语言风格、描写细节、主题主旨。

每节写法：
· 第一句给论点，直接下判断。
· 接一个加粗的术语做小标题（**切片式叙事：** **起承转合的内化：**），
  后面跟两三句展开。
· 引原文做证据，引文嵌在句子里，用引号，不要单独成行。
· 评价词用：巧妙地、精准地、极为出色、拿捏得恰到好处、极具辨识度。

语气克制：几乎不用感叹号，第一人称只出现在必要处。
最后一节要把主题往上收一层，但不要说教。
```

### 少量负面

```text
不要用感叹号连用，不要「啊啊啊」。
不要大段复述剧情——引原文是为了分析，不是为了讲一遍故事。
不要在结尾写「总而言之，这是一部值得一读的佳作」这种套话。
```

## 三、同人

### 数据长什么样

| 指标 | 数值 |
| --- | --- |
| 篇幅 | 中位 **4474 字**（一批里往往是 2–4 篇） |
| 问号 | **5.1 / 千字**（三类最高，因为对话多） |
| 省略号 | 4219 处（大量「……」起句） |
| 感叹号 | 3.7 / 千字 |
| 「我」 | 10.2 / 千字、「你」9.8 / 千字 |

### 读出来的样子

**标题是《关于X这件事》式**：`《关于夜雁每天都要抱抱这件事》`。

**对话驱动，段落极短**，一两句一段：

> "朝舞姐姐——"
>
> 朝舞的笔尖一顿，还没反应过来，后背就撞进一个温热的怀抱。

**省略号起句**是标志性的：`"……你们每天都这样，不腻吗？"`

**心理全部外化成动作**：不说"朝舞有点动摇"，写"笔尖又在纸上停留了一瞬"。

**角色口癖必须保住**：清霜的"……不要。""……随便。"，夜雁的"我知道呀""不腻！"。

**结尾定格在一个动作上**，不总结、不升华：

> 夜雁嘿嘿笑了两声，继续把下巴搁回她头顶，嚼薯片的节奏都欢快了几分。

### 正面提示词（主体）

```text
写一篇同人，标题用《关于X这件事》的句式。

写法：
· 对话占全篇一半以上，一问一答推着走。
· 段落极短，一到两句就分段。
· 用「……」起句表示迟疑、被打断、没说完。
· 心理活动一律写成动作：不写「她有点动摇」，写「笔尖在纸上停了一瞬」。
· 每个角色保留自己的口癖和说话节奏——懒的人句子短、爱用省略号；
  元气的人句子长、带感叹号；冷静的人只答一两个字。
· 场景里要有具体的生活物件：薯片、热水、沙发垫、笔记本。
· 结尾定格在一个动作或一个画面上，不解释、不总结。

篇幅 1500–3000 字。
```

### 少量负面

```text
不要大段心理独白。
不要在结尾升华或点题。
不要让所有角色用同一种语气说话。
```

## 四、三类共通的三条

1. **具体压过抽象。** 三类都在写"薯片""虾片""笔记本""灯沿"这种实物，没有一篇在写"情感张力""叙事张力"这种空词。
2. **引用必须落在动作或台词上。** 短评引一句台词，长评引一个细节，同人写一个动作。三者都不复述剧情。
3. **情绪浓度按体裁递减。** 短评 9.3 个感叹号/千字，同人 3.7，长评 0.8。**这是三类最硬的分界线**，比长度可靠得多。

## 五、怎么用到 App 里

| 位置 | 现在 | 建议 |
| --- | --- | --- |
| `BASE_RULE` | 通用读者规则 | 保留，但把"情绪最多两处"删掉——语料里短评远不止两处 |
| `STYLES` 五人格式 | 追问/挑剔/考据/强调/物件 | 换成上面的**分工制**：角色厨/CP党/考据党/路人/差评/催更 |
| 长评 | 三节赏析 | 改成六节，加"四字判断"小标题 |
| 同人 | 物件视角 | 改成对话驱动 + 短段落 + 案例里的口癖保持 |

最该改的是**短评的分工**：现在的五个人格是"说话方式"，语料里的一批是"读者类型"。后者才像真的评论区。
